# Логотип EHROZ

Буквы собраны на одной сетке: вертикальный штрих 64, горизонтальный 54, высота буквы 224.
У E и H общая верхняя перекладина, ножка R и полосы Z идут под одним углом, R и O скруглены одинаково.

| Файл | Что это |
|---|---|
| `ehroz-line-*.svg` | Строка: для шапки сайта, подписей, узких мест |
| `ehroz-block-*.svg` | Вертикальный блок: обложки, аватар, крупные размеры |
| `ehroz-favicon.svg` | Фавиконка: узкая Z на тёмной плашке |

Цвета: `black` и `white` — одноцветные; `color-on-light` — тёмные буквы и кобальт #2340C8 для светлого фона;
`color-on-dark` — светлые буквы и кобальт #7C93FF для тёмного фона. Фон у всех файлов, кроме фавиконки, прозрачный.
