# ehroz.pro

Витрина приложений Ehroz: главная в духе рабочего стола macOS (строка меню, Dock, Spotlight по ⌘K,
живые обои) и страница-презентация для каждого приложения с анимированными сценами интерфейса.

**Astro 5 · TypeScript · Tailwind 4 · свой WebGL-шейдер · без трекеров по умолчанию** (аналитика — только с согласия, см. `SEO.md`). RU — `/`, EN — `/en/`.

## Как добавить приложение (за минуту)

1. Положите иконку `assets-src/icons/<slug>.png` (1024×1024, с полями, как у иконок macOS) и выполните
   `npm run icons`.
2. Скопируйте любой объект в `src/content/apps.ts` и поменяйте поля: название, тексты RU/EN, платформы,
   статус, цвета (`accent`, `glow`), ссылки, фичи, шаги, FAQ, требования.
3. В `features[].scene` укажите `'generic'` — получится простая сцена с подписью. Живую сцену можно
   нарисовать в `src/components/scenes/` и подключить в `SceneSwitch.astro`, а сценарий анимации —
   в `src/scripts/scenes-more.ts` через `register('<id>', async (c) => { … })`.

Страница, OG-картинка, Dock, Spotlight и sitemap появятся сами.

## Где что

| Путь | Что внутри |
|---|---|
| `src/content/apps.ts` | все продукты и тексты |
| `src/i18n.ts` | контакты и подписи интерфейса RU/EN |
| `src/components/` | строка меню, Dock, Spotlight, карточки, страница приложения |
| `src/components/scenes/` | сцены интерфейсов приложений (HTML/CSS/SVG) |
| `src/scripts/` | обои (WebGL), сценарии сцен, интерактив |
| `src/lib/og.ts` | генерация OG-картинок при сборке |
| `scripts/icons.mjs` | иконки и фавиконки из `assets-src/` |
| `projects.md` | разведка: все проекты и что попало на витрину |
| `DECISIONS.md` | что решено без согласования и что проверить |
| `DEPLOY.md` | публикация, домен, индексация, поисковые системы |
| `PAGE-STANDARD.md` | **стандарт новой страницы**: правила, шаблон, чек-лист перед публикацией |
| `SEO.md` | микроразметка, нейросети, аналитика, безопасность, доступность — что сделано и что вручную |
| `src/lib/schema.ts` | микроразметка schema.org |
| `src/analytics.config.ts` | ID GA4 и Яндекс Метрики (пусто = без счётчиков) |
