# SEO, GEO, безопасность и аналитика ehroz.pro

Статус по чек-листу. ✅ сделано в коде · 👤 нужно сделать вручную (аккаунты, DNS) · ➖ не относится к сайту
(статическая витрина: нет форм, базы, логинов и админки).

Проверки: `npm run build && npm run check:seo` (перед публикацией), `node scripts/monitor-seo.mjs` (живой сайт).
Техническое SEO, индексация и панели вебмастеров — в `DEPLOY.md`.

## Микроразметка Schema.org (JSON-LD)

Код: `src/lib/schema.ts`. Каждая страница отдаёт **один граф** (`@graph`): сущности ссылаются друг на друга
через `@id`, поэтому сайт и автор описаны одинаково везде и разметка не противоречит сама себе.

| Тип | Где | Статус |
|---|---|---|
| WebSite | все страницы | ✅ |
| WebPage / CollectionPage / ProfilePage / ContactPage | все страницы: название, описание, язык, обложка (ImageObject), автор, dateModified | ✅ |
| BreadcrumbList | приложения, «Об Ehroz», «Контакты» — совпадает с видимыми хлебными крошками | ✅ |
| Person | автор и владелец; ссылки на профили (sameAs) | ✅ |
| SoftwareApplication / WebApplication | страницы приложений: платформы, версия, функции, иконка, автор, дата | ✅ |
| Offer | только у вышедших приложений, бесплатность указана в их тексте | ✅ |
| FAQPage | страницы приложений — те же вопросы, что видны на странице | ✅ |
| ItemList | главная — каталог приложений | ✅ |
| ImageObject | обложки страниц и иконки приложений | ✅ |
| Organization | ➖ компании нет, приложения делает один человек — используется Person |
| Article, NewsArticle, BlogPosting | ➖ статей и блога нет. Появится блог — добавьте узел в `schema.ts` |
| Product | ➖ это программы, для них правильный тип SoftwareApplication |
| VideoObject | ➖ видео на сайте нет (анимации интерфейсов — это HTML, не видео) |
| LocalBusiness, Event | ➖ нет офиса и мероприятий |
| HowTo | ➖ Google убрал расширенные результаты HowTo в 2023; шаги «Как это работает» и так в HTML |

Правила соблюдены и проверяются в `check:seo`: валидный JSON, один граф, без повторов `@id`, все ссылки `@id`
существуют, нет рейтингов и отзывов (реальных данных нет), вопросы FAQ есть в тексте страницы,
у каждой страницы есть dateModified. Дата — поле `updated` в `src/content/apps.ts`, меняйте его при правке текста.

👤 Разово проверить в [валидаторе Schema.org](https://validator.schema.org/) и
[Rich Results Test](https://search.google.com/test/rich-results) после деплоя.

## Нейросети (GEO / AEO)

- ✅ Сайт открыт без авторизации, CAPTCHA и JS-барьеров: весь текст — в готовом HTML (SSG), проверено без JS.
- ✅ `robots.txt` явно разрешает поисковых и AI-роботов: Googlebot, Bingbot, YandexBot, **OAI-SearchBot**,
  ChatGPT-User, PerplexityBot, Claude-SearchBot и др. Роботы **обучения** (GPTBot, Google-Extended, ClaudeBot,
  CCBot…) — отдельная группа и отдельный флажок `ALLOW_AI_TRAINING` в `src/pages/robots.txt.ts` (сейчас разрешено).
  Запрет обучения не влияет на видимость в ChatGPT Search.
- ✅ `/llms.txt` — краткая карта сайта для нейросетей, `/llms-full.txt` — полный текст всех страниц приложений
  (RU и EN). Собираются из `apps.ts`, поэтому всегда совпадают с сайтом.
- ✅ У каждой страницы одна тема, страница приложения начинается с сути (слоган + абзац «что это»), дальше
  функции, шаги, FAQ, требования. Есть автор, дата обновления, версия, платформы, статус.
- ✅ Названия продуктов единообразны: источник один — `apps.ts`.
- ✅ Нет почти одинаковых страниц: 11 приложений × 2 языка, связанных через hreflang.
- 👤 Vercel → проект → **Firewall**: не включайте *Attack Challenge Mode* / *Bot Protection* для всего сайта
  постоянно — они показывают роботам проверку вместо страницы.
- 👤 Контент, который поможет ссылаться на сайт: сравнения приложений с аналогами, цифры (скорость, размеры
  файлов), ссылки на первоисточники (форматы, модели распознавания речи). Это тексты — их пишет автор.

## Аналитика

Сайт по умолчанию без трекеров. Код готов, включается вписыванием ID в `src/analytics.config.ts`.

- 👤 Создать ресурс GA4 и счётчик Яндекс Метрики, вписать ID. Метрика: вебвизор выключен.
- ✅ **Согласие на cookies**: до нажатия «Разрешить» не загружается ни один скрипт и не ставится ни одной cookie.
  «Настройки cookies» в подвале — отозвать или дать согласие. CSP сама разрешит домены счётчиков.
- ✅ События (одинаковые в GA4 и как цели в Метрике), код — `src/scripts/analytics.ts`:

  | Событие | Что значит |
  |---|---|
  | page_view | просмотр страницы (автоматически) |
  | download_click | «Скачать» / «Все версии» — конверсия |
  | open_app_click | «Открыть» веб-приложение — конверсия |
  | contact_click | Telegram или email — конверсия (заявка) |
  | order_click | «Заказать сайт» — конверсия |
  | internal_click / outbound_click | переходы по сайту и на внешние сайты |
  | scroll_depth (25/50/75/90), read_complete | глубина прокрутки и дочитывание |
  | search | запросы в поиске ⌘K и число результатов |
  | language_switch | смена языка |
  | page_not_found, js_error | 404 и ошибки JavaScript |

- 👤 В GA4 отметить download_click, open_app_click, contact_click, order_click как **ключевые события**;
  в Метрике создать цели типа «JavaScript-событие» с теми же именами.
- 👤 Регулярные отчёты: GA4 → *Библиотека отчётов* / Looker Studio с рассылкой; Метрика → *Отчёты по email*.
- ➖ Регистрации, подписки, покупки, фильтры — на сайте их нет.

## Безопасность и надёжность

- ✅ HTTPS везде, HSTS, редирект http → https (Vercel).
- ✅ **Content Security Policy**: при сборке (`src/lib/csp.ts`) в каждую страницу встраивается политика с
  хешами её inline-скриптов — внедрённый чужой скрипт не выполнится. Плюс заголовки (`vercel.json`,
  `public/_headers`): `frame-ancestors 'none'`, X-Frame-Options, X-Content-Type-Options, Referrer-Policy,
  Permissions-Policy, Cross-Origin-Opener-Policy.
- ➖ CSRF, защита форм от спама, rate limiting, хранение паролей, админ-панель — на сайте нет форм, бэкенда,
  логинов и админки. Ключей API в коде нет (ключ IndexNow публичный по протоколу).
- ✅ Резервные копии: весь сайт — в git (GitHub), каждый деплой хранится в Vercel и откатывается за минуту.
- ✅ Мониторинг доступности: `.github/workflows/uptime.yml` каждый час; при сбое GitHub пришлёт письмо.
  Еженедельный SEO-мониторинг дополнительно проверяет внешние ссылки (битые = 404/410).
- ✅ Зависимости: Dependabot (`.github/dependabot.yml`) раз в неделю открывает PR с обновлениями.
- 👤 **Astro 5 → 7**: `npm audit` показывает уязвимости в Astro 5. Они касаются серверного рендеринга и
  обработки чужих данных, а сайт полностью статический, поэтому риск для живого сайта низкий. Но обновиться
  стоит — это переход через две мажорные версии, отдельная задача.
- 👤 Уведомления об ошибках Vercel: *Settings → Notifications* — включить письма о неудачных деплоях.
